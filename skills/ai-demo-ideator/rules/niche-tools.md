# Outils IA niche, méconnus & plateformes "wow"

Outils et plateformes peu connus ou émergents qui créent un effet wow en démo. Loin des classiques (OpenAI, Anthropic, Google) — ici on explore les pépites.

---

## Inference ultra-rapide & plateformes alternatives

### Groq — L'inférence à la vitesse de la lumière
- **Quoi** : Hardware custom (LPU) qui fait tourner des LLM à 750-900 tokens/sec — 20x plus rapide que GPU
- **Wow** : Les réponses apparaissent INSTANTANEMENT. Le public n'en croit pas ses yeux.
- **API** : Compatible OpenAI, drop-in replacement
- **URL** : groq.com
- **Démo** : "Regardez ce chatbot répondre avant que vous ayez fini de lire la question"
- **Complexité** : Rapide (1h pour switcher une app existante)

### OpenRouter — Une API, tous les modèles
- **Quoi** : Marketplace d'inférence, 300+ modèles via une seule API compatible OpenAI
- **Wow** : Un seul API key pour Claude, GPT, Llama, DeepSeek, Mistral, Qwen...
- **URL** : openrouter.ai
- **Démo** : "Comparons la même question sur 5 modèles différents en temps réel"
- **Complexité** : Rapide (30 min)

### Together AI — Open Source à l'échelle
- **Quoi** : Inférence haute performance pour 200+ modèles open source, sub-100ms latence
- **URL** : together.ai
- **Démo** : "Voici Llama 4 Maverick qui tourne aussi vite que GPT-5.4 — pour 1/10e du prix"

### SiliconFlow — Alternative low-cost
- **Quoi** : Plateforme d'inférence all-in-one, 2.3x plus rapide que les concurrents cloud
- **URL** : siliconflow.com
- **Démo** : Idéal pour montrer que l'IA de pointe n'est pas réservée aux gros budgets

### Ollama — LLM en local, une commande
- **Quoi** : Run n'importe quel LLM localement avec `ollama run llama4`
- **Wow** : Zéro cloud, zéro API key, zéro coût, 100% privé
- **URL** : ollama.ai
- **Démo** : "Regardez, j'ai une IA aussi capable que ChatGPT qui tourne sur mon laptop — offline"
- **Complexité** : Rapide (10 min)

## 3D — Les pépites

### Tripo AI 3.0 — Text/Sketch to 3D
- **Quoi** : Modèle 2B paramètres, topologie propre (quad-based), auto-rigging, export game-ready
- **Wow** : Dessinez un croquis → modèle 3D riggé et animable en 30 secondes
- **URL** : tripo3d.ai
- **Démo** : "Dessinons un personnage au crayon... et voilà son modèle 3D prêt pour Unity"
- **Complexité** : Rapide (accès web)

### Meshy — Itération rapide
- **Quoi** : Text-to-3D et image-to-3D avec plugins Blender, Unity, Unreal
- **URL** : meshy.ai
- **Démo** : "Photo de votre tasse de café → modèle 3D en 10 secondes"

### Rodin AI (Hyper3D/Deemos) — Ultra photoréaliste
- **Quoi** : Modèles 3D avec textures PBR 4K, qualité produit
- **Démo** : "Photo produit → rendu 3D indiscernable de la réalité"

### Luma AI Genie — Capture de scènes
- **Quoi** : NeRF avancé pour capturer et recréer des scènes réelles en 3D
- **URL** : lumalabs.ai
- **Démo** : "Filmez une pièce avec votre téléphone → scène 3D navigable"

## Vibe Coding — Les plateformes app-builder IA

### Bolt.new — L'IA qui debug en temps réel
- **Quoi** : Génère du code live, a accès au filesystem, terminal, console navigateur — voit ses erreurs et les corrige seule
- **Wow** : Regarder l'IA coder, crasher, lire l'erreur, et se corriger est hypnotisant
- **URL** : bolt.new
- **Complexité** : Rapide (navigateur)
- **Supporte** : React, Vue, Svelte, Angular, Astro, Remix, Next.js

### Lovable — Le plus accessible
- **Quoi** : Décrivez votre app → UI, backend, DB schema, auth, déploiement — tout depuis un navigateur
- **URL** : lovable.dev
- **Démo** : "Je veux une app de réservation de salles" → app déployée avec auth en 10 min

### Replit Agent 4 — Du texte à l'app native
- **Quoi** : Décrivez votre idée → plan, code, test, déploiement automatique. Génère même des apps iOS via React Native.
- **URL** : replit.com/ai
- **Démo** : "Crée-moi une app de suivi d'habitudes" → app déployée et fonctionnelle

### Kiro (AWS) — IDE agentique
- **Quoi** : Agents autonomes en background qui génèrent docs, tests, optimisations selon des specs. MCP natif.
- **URL** : kiro.dev
- **Démo** : L'IDE qui écrit vos tests et votre doc pendant que vous codez

## Coding assistants niche

- **Quoi** : Open source, 39K+ GitHub stars, voice-to-code, mapping automatique du codebase
- **URL** : aider.chat
- **Démo** : "Dictez des instructions à votre terminal → le code se modifie en temps réel"

### Zencoder — Multi-agents sur votre codebase
- **Quoi** : "Repo Grokking" = analyse profonde cross-codebase. Pipeline agentic avec plusieurs IA en parallèle. 100+ outils MCP visuels.
- **URL** : zencoder.ai
- **Démo** : "3 agents analysent simultanément 3 aspects différents de votre code"

### Continue — Cursor open source
- **Quoi** : Assistant IA pour VS Code/JetBrains, open source, bring-your-own-model
- **URL** : continue.dev
- **Démo** : "Comme Cursor mais gratuit et avec le modèle de votre choix"
